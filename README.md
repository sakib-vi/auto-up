# GitHub Auto Uploader Tool 🚀

এটি একটি পাইথন ভিত্তিক অটোমেশন টুল, যার সাহায্যে খুব সহজে টার্মিনাল থেকেই যেকোনো লোকাল প্রজেক্ট গিটহাবে আপলোড এবং আপডেট করা যায়।

## বৈশিষ্ট্যসমূহ (Features)
- 🔧 নতুন গিট রিপোজিটরি সেটআপ করা।
- 📁 এক ক্লিকে সব ফাইল গিটহাবে পুশ করা।
- 💾 অটোমেটিক বা কাস্টম কমিট মেসেজ দেওয়া।
- 📊 গিট স্ট্যাটাস চেক করা।

## কীভাবে ব্যবহার করবেন (Usage)
১. আপনার কম্পিউটারে Python এবং Git ইনস্টল থাকতে হবে।
২. টার্মিনালে নিচের কমান্ডটি লিখে স্ক্রিপ্টটি রান করুন:
   ```bash
   python "python github_uploader.py"
   ```
৩. স্ক্রিনের মেনু থেকে আপনার পছন্দমতো অপশন সিলেক্ট করুন।
